# tmpmask — портал фильтров

Программа показывает видео с вашей камеры. Если сложить большие и указательные пальцы
обеих рук так, чтобы получилась рамка, внутри неё появляется «портал» — часть кадра с
цветовым фильтром (фиолетовый, тепловизор, негатив и другие). Двигайте руки — портал
движется за ними. Всё работает локально, видео никуда не отправляется.

## Установка

Нужен Python 3.12 и веб-камера.

```bash
git clone <адрес репозитория> tmpmask
cd tmpmask
python3.12 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .
```

Файл модели распознавания рук должен лежать в `models/hand_landmarker.task`. Если его
нет, скачайте:

```bash
mkdir -p models
curl -L -o models/hand_landmarker.task https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task
```

## Запуск

```bash
python -m tmpmask
```

Откроется окно с изображением камеры. Поднимите обе руки перед камерой и сложите пальцы
в рамку: большой и указательный каждой руки образуют углы портала.

Примеры:

```bash
python -m tmpmask --filter thermal
python -m tmpmask --camera 1 --width 1920 --height 1080
python -m tmpmask --no-mirror --output-dir ~/Videos/tmpmask
python -m tmpmask --help
```

## Управление

Клавиши работают, когда активно окно программы. Включите английскую раскладку:
русские буквы окно не получает.

| Действие                 | Клавиша или жест                                   |
|--------------------------|----------------------------------------------------|
| Следующий фильтр         | `N` или щипок (все пальцы одной руки сведены вместе) |
| Предыдущий фильтр        | `P`                                                |
| Выбрать фильтр по номеру | `1`–`8`                                            |
| Скриншот                 | `S`                                                |
| Начать / остановить запись видео | `R` (пока идёт запись, в углу горит красная точка) |
| Выход                    | `Q` или `Esc` (или закрыть окно)                   |

Номера фильтров: 1 — Фиолетовый, 2 — Тепловизор, 3 — Негатив, 4 — Чёрно-белый,
5 — Океан, 6 — Сепия, 7 — Пиксели, 8 — Контуры.

Портал появляется, только когда в кадре ровно две руки. Если рука пропала, портал
плавно гаснет.

## Параметры командной строки

| Параметр | Значение | По умолчанию | Что делает |
|----------|----------|--------------|------------|
| `--camera` | число ≥ 0 | `0` | Номер камеры |
| `--width` | число > 0 | `1280` | Запрашиваемая ширина кадра |
| `--height` | число > 0 | `720` | Запрашиваемая высота кадра |
| `--mirror` / `--no-mirror` | — | зеркало включено | Зеркальное отражение картинки |
| `--filter` | `purple`, `thermal`, `invert`, `gray`, `ocean`, `sepia`, `pixelate`, `edges` | `purple` | Фильтр при запуске |
| `--output-dir` | путь | `captures` | Папка для скриншотов и видео |
| `--model` | путь | `models/hand_landmarker.task` | Файл модели распознавания рук |

Камера может выдать кадр другого размера, чем запрошено, — это нормально.

## Куда сохраняются файлы

Скриншоты (`tmpmask_ГГГГММДД_ЧЧММСС.png`) и видео (`tmpmask_ГГГГММДД_ЧЧММСС.mp4`)
попадают в папку `captures` рядом с местом запуска или в ту, что указана в
`--output-dir`. Папка создаётся сама. Путь к каждому файлу печатается в консоли.
В скриншотах и видео красной точки записи нет.

## Если что-то не работает

**Камера не открывается (macOS).** Откройте «Системные настройки → Конфиденциальность и
безопасность → Камера» и разрешите доступ программе, из которой запускаете tmpmask
(Терминал, iTerm, редактор кода). Затем запустите снова. Если камер несколько,
попробуйте `--camera 1`.

**Камера не открывается (Windows, Linux).** Закройте другие программы, которые
используют камеру. На Linux проверьте, что вы в группе `video` и существует
устройство `/dev/video0`.

**«Не найден файл модели».** Скачайте модель командой из раздела «Установка» или
укажите свой файл через `--model`.

**Клавиши не реагируют.** Щёлкните по окну программы и переключитесь на английскую
раскладку.

**Портал не появляется.** Нужны ровно две руки в кадре, хорошее освещение и открытые
большие и указательные пальцы. Отойдите от камеры чуть дальше.

**Нельзя сохранить файлы.** Укажите другую папку через `--output-dir`: у текущей нет
прав на запись.
