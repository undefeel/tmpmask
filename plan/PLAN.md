# tmpmask — план

## Цель

Десктопное приложение «портал фильтров» по референсу `ref/*.mov` (локально, в git не
входит). Веб-камера в окне; две руки задают четырёхугольный «портал» кончиками большого
и указательного пальцев каждой руки; внутри портала к видео применяется фильтр,
по контуру — тонкая белая рамка. Фильтры листаются жестом «щепоть» (все пальцы одной
руки сведены вместе) и клавишами.

Первая версия:
- 8 фильтров из референса: фиолетовая заливка, тепловая карта, негатив, ч/б,
  синяя палитра, сепия, пикселизация, контуры;
- переключение жестом и клавишами (следующий/предыдущий, прямой выбор 1–8);
- сглаживание дрожания точек портала и плавное появление/исчезновение;
- скриншот (PNG) и запись видео (MP4) по клавише в папку вывода;
- настройки через аргументы CLI: камера, разрешение, зеркалирование, стартовый
  фильтр, папка вывода, путь к модели.

Вне первой версии: надписи поверх кадра, веб/мобильная версия, звук.

## Архитектура

Пакет `tmpmask/`, каждый модуль — чистая логика с тестами без камеры:

| Модуль | Ответственность |
|--------|-----------------|
| `handtypes.py` | Общие типы: `Point`, `Hand` (handedness + 21 точка в пикселях), индексы landmark |
| `tracker.py` | Обёртка MediaPipe HandLandmarker (Tasks API, режим VIDEO) → `list[Hand]` |
| `portal.py` | Четырёхугольник из двух рук, маска, применение фильтра внутри с прозрачностью, рамка |
| `smoothing.py` | EMA-сглаживание точек портала, fade-in/fade-out, удержание при кратковременной потере рук |
| `gestures.py` | Детектор щепоти: срабатывает по фронту, с кулдауном |
| `filters.py` | Реестр 8 фильтров: `id` → функция `BGR кадр → BGR кадр` |
| `capture.py` | Скриншоты PNG и запись MP4 с именами по времени |
| `texts.toml` + загрузчик | Все русские тексты: названия фильтров, справка CLI, сообщения |
| `config.py` | Разбор аргументов CLI |
| `app.py`, `__main__.py` | Главный цикл: камера → трекер → жесты/клавиши → портал → окно/запись. Цикл принимает источник кадров и трекер параметрами, чтобы тестироваться без камеры |

Порядок точек портала: руки сортируются по x запястья на экране;
полигон = [левый указательный, правый указательный, правый большой, левый большой].
Самопересечение («бантик», когда руки перекручены) допустимо — как в референсе.

Модель: `models/hand_landmarker.task` (официальная модель MediaPipe, Apache-2.0,
~8 МБ) — скачивает и коммитит координатор перед этапом 02, воркеры в сеть за ней не ходят.

## Стек

- Python 3.12 (`/opt/homebrew/bin/python3.12`), venv `.venv` в корне worktree.
- `opencv-python`, `mediapipe` (Tasks API, не устаревший `mp.solutions`), `numpy`.
- Тесты: `pytest`; линтер: `ruff`. Сборка: `pyproject.toml` (setuptools), extras `dev`.
- Подготовка окружения: `/opt/homebrew/bin/python3.12 -m venv .venv && .venv/bin/pip install -e '.[dev]'`
- Команда полной проверки: `.venv/bin/ruff check . && .venv/bin/pytest -q`
- Запуск: `.venv/bin/python -m tmpmask`

## Соглашения

- Идентификаторы и комментарии — на английском; тексты для пользователя — на русском,
  только в `tmpmask/texts.toml`.
- Id фильтров: `purple`, `thermal`, `invert`, `gray`, `ocean`, `sepia`, `pixelate`, `edges`,
  `sabertooth` (порядок листания именно такой; `sabertooth` — оверлей-картинка, см. этап 05).
- Документы идей: `docs/design/<тема>.md`; черновики цепочки: `drafts/<ID>/` (удаляются
  в мерж-коммите).
