## Target
Empty repository (only `README.md`, `CLAUDE.md`, `plan/`). Create the Python package skeleton for `tmpmask`.

## Change
1. `pyproject.toml` (setuptools build backend): project name `tmpmask`, version `0.1.0`, `requires-python = ">=3.12"`, dependencies `opencv-python`, `mediapipe`, `numpy`; optional extra `dev = ["pytest", "ruff"]`. Package data: include `tmpmask/*.toml`. Ruff config: `line-length = 100`, `target-version = "py312"`, lint select `["E", "F", "I", "UP", "B"]`. Pytest config: `testpaths = ["tests"]`.
2. `.gitignore`: `.venv/`, `__pycache__/`, `*.egg-info/`, `.pytest_cache/`, `.ruff_cache/`, `captures/`, `.DS_Store`, `ref/`.
3. `tmpmask/__init__.py`: `__version__ = "0.1.0"`.
4. `tmpmask/__main__.py`: a `main()` that currently does nothing and returns 0; `if __name__ == "__main__": raise SystemExit(main())`.
5. `tmpmask/handtypes.py` — shared types used by every later module (exact API, do not rename):
   ```python
   Point = tuple[float, float]  # pixel coordinates (x, y)

   WRIST = 0
   THUMB_TIP = 4
   INDEX_TIP = 8
   MIDDLE_MCP = 9
   MIDDLE_TIP = 12
   RING_TIP = 16
   PINKY_TIP = 20
   FINGERTIPS = (THUMB_TIP, INDEX_TIP, MIDDLE_TIP, RING_TIP, PINKY_TIP)

   @dataclass(frozen=True)
   class Hand:
       handedness: str            # "Left" or "Right" as reported by MediaPipe
       points: tuple[Point, ...]  # exactly 21 landmarks in pixels

       def __post_init__(self): ...  # raise ValueError unless len(points) == 21

       def point(self, index: int) -> Point: ...

       def size(self) -> float: ...  # distance WRIST -> MIDDLE_MCP, used as hand scale
   ```
6. `tests/__init__.py` (empty) and `tests/test_handtypes.py`: valid construction, `ValueError` on 20 points, `point()`, `size()` on a known geometry; plus a smoke test that `tmpmask.__main__.main()` returns 0.
7. `models/.gitkeep` (empty) — the hand model will be added there later by the coordinator.
