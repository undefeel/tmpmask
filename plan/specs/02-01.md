# 02-01: Filter registry

## Target
New module `tmpmask/filters.py` and its tests. Existing: `tmpmask/handtypes.py` (not needed here).

## Change
Implement eight image filters and an ordered registry.

```python
FilterFn = Callable[[np.ndarray], np.ndarray]  # BGR uint8 HxWx3 in -> BGR uint8 HxWx3 out

FILTER_IDS: tuple[str, ...] = ("purple", "thermal", "invert", "gray", "ocean", "sepia", "pixelate", "edges")

def get_filter(filter_id: str) -> FilterFn: ...   # KeyError on unknown id
def next_filter_id(current: str, step: int = 1) -> str: ...  # cyclic over FILTER_IDS, step may be negative
```

Filters (input must not be mutated; output same shape and dtype as input):
- `purple`: blend with solid purple BGR `(160, 32, 128)`, weight 0.6 for the colour (`cv2.addWeighted`).
- `thermal`: grayscale → `cv2.applyColorMap(..., cv2.COLORMAP_JET)`.
- `invert`: `255 - frame`.
- `gray`: grayscale converted back to 3-channel BGR.
- `ocean`: grayscale → `cv2.COLORMAP_OCEAN`.
- `sepia`: classic sepia matrix applied in RGB order (`tr = .393r+.769g+.189b`, `tg = .349r+.686g+.168b`, `tb = .272r+.534g+.131b`), clipped to 0..255.
- `pixelate`: block size 16 px — downscale with `INTER_LINEAR` to `max(1, w//16) x max(1, h//16)`, upscale back with `INTER_NEAREST`.
- `edges`: `cv2.Canny(gray, 80, 160)`; edge pixels coloured cyan BGR `(255, 255, 0)` on a black background.

## Constraints
- Pure functions, no global state, no I/O, no display.
- Must work for any size ≥ 1x1 (including 1x1 and odd sizes) without exceptions.
- No user-facing text in this module (Russian names live elsewhere, keyed by these ids).

## Ownership
`tmpmask/filters.py`, `tests/test_filters.py`.

## Observable acceptance
`tests/test_filters.py` covers, for every id: same shape/dtype, input unchanged, output differs from a non-uniform random input; `pixelate` on 1x1 and 17x9; `edges` on a black frame gives all zeros; `next_filter_id` wraps both directions; `get_filter("nope")` raises `KeyError`.
