# 02-02: Portal geometry and rendering

## Target
New module `tmpmask/portal.py` and its tests. Uses `tmpmask/handtypes.py` (`Hand`, `Point`, `THUMB_TIP`, `INDEX_TIP`, `WRIST`) — read it, do not change it.

## Change
```python
Quad = tuple[Point, Point, Point, Point]

def portal_quad(hands: Sequence[Hand]) -> Quad | None: ...
def render_portal(frame: np.ndarray, quad: Quad, filter_fn: Callable[[np.ndarray], np.ndarray],
                  opacity: float = 1.0, outline: bool = True) -> np.ndarray: ...
```
- `portal_quad`: returns `None` unless exactly two hands. Sort hands by the x of their `WRIST` point (smaller x = "left on screen"; ignore `handedness`). Return `(left.INDEX_TIP, right.INDEX_TIP, right.THUMB_TIP, left.THUMB_TIP)`.
- `render_portal`: returns a new frame (input not mutated). Build a mask by `cv2.fillPoly` of the quad (rounded to int, clipped into the frame); a self-intersecting "bow-tie" quad is allowed and is filled as `fillPoly` fills it. Apply `filter_fn` to the full frame (or bounding box crop — your choice), then inside the mask: `out = frame*(1-opacity) + filtered*opacity`. `opacity` is clamped to 0..1; with opacity 0 the output equals the input everywhere except the outline. If `outline` and opacity > 0, draw the closed quad with `cv2.polylines`, white `(255,255,255)`, thickness 1, `cv2.LINE_AA`.
- Degenerate quads (all points equal, collinear, fully outside the frame) must not raise.

## Constraints
- Pure functions, no global state, no display, no I/O.
- Do not import `tmpmask.filters` (it is developed in parallel); tests use their own simple filter (e.g. invert).

## Ownership
`tmpmask/portal.py`, `tests/test_portal.py`.

## Observable acceptance
Tests: `portal_quad` with 0/1/3 hands → `None`; with two hands given in either order the point order is as specified; a pixel well inside a 100x100 square quad is filtered and a pixel outside is untouched (`outline=False`); opacity 0 → identical to input with `outline=False`; opacity 0.5 → midpoint value; degenerate and out-of-frame quads do not raise; input frame not mutated.
