# 02-04: Pinch gesture detector

## Target
New module `tmpmask/gestures.py` and its tests. Uses `tmpmask/handtypes.py` (`Hand`, `FINGERTIPS`, `Hand.size()`) — read only.

## Change
```python
def is_pinch(hand: Hand, ratio: float = 0.35) -> bool: ...

class PinchTrigger:
    def __init__(self, ratio: float = 0.35, cooldown_s: float = 0.8, release_frames: int = 3): ...
    def update(self, hands: Sequence[Hand], now_s: float) -> bool: ...
```
- `is_pinch`: centroid of the five `FINGERTIPS`; true when every fingertip is closer to the centroid than `ratio * hand.size()`. A hand with `size() == 0` is never a pinch.
- `PinchTrigger.update` returns `True` exactly once per pinch (rising edge): when any hand is pinching now, no hand was pinching on the previous "armed" state, and at least `cooldown_s` passed since the last trigger. After a trigger it re-arms only after `release_frames` consecutive calls where no hand is pinching. `now_s` is a monotonic time in seconds supplied by the caller (no clock inside).

## Constraints
- Deterministic, no clock, no I/O.

## Ownership
`tmpmask/gestures.py`, `tests/test_gestures.py`.

## Observable acceptance
Tests build synthetic `Hand`s (open hand with spread fingertips, pinched hand with fingertips clustered): open → `is_pinch` False; pinched → True; zero-size hand → False; holding a pinch for 30 frames triggers once; pinch, release 3 frames, pinch again after cooldown → second trigger; release < 3 frames → no second trigger; second pinch within cooldown → no trigger; empty hand list → False.
