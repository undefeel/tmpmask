# 02-05: MediaPipe hand tracker

## Target
New module `tmpmask/tracker.py` and its tests. Model file `models/hand_landmarker.task` is already in the repository. Uses `tmpmask/handtypes.py` (`Hand`) — read only.

## Change
```python
DEFAULT_MODEL_PATH: Path  # <repo root>/models/hand_landmarker.task, resolved relative to this file

def landmarks_to_hands(hand_landmarks, handedness, width: int, height: int) -> list[Hand]: ...

class HandTracker:
    def __init__(self, model_path: Path | str = DEFAULT_MODEL_PATH, max_hands: int = 2,
                 min_detection_confidence: float = 0.5, min_tracking_confidence: float = 0.5): ...
    def detect(self, frame_bgr: np.ndarray, timestamp_ms: int) -> list[Hand]: ...
    def close(self) -> None: ...
    # context manager: __enter__ / __exit__ call close()
```
- Use the MediaPipe **Tasks API**: `mediapipe.tasks.python.vision.HandLandmarker` with `RunningMode.VIDEO`, `num_hands=max_hands`, created via `HandLandmarkerOptions(base_options=BaseOptions(model_asset_path=...))`. Do not use `mp.solutions`.
- `detect`: BGR → RGB, `mp.Image(image_format=mp.ImageFormat.SRGB, data=rgb)`, `detect_for_video(image, timestamp_ms)`. Timestamps must be strictly increasing: if the caller passes a value ≤ the previous one, use previous + 1.
- `landmarks_to_hands`: pure conversion. `hand_landmarks` is a list (per hand) of 21 objects with `.x`, `.y` normalized to 0..1; `handedness` is a list (per hand) of lists of objects with `.category_name`. Pixel point = `(x * width, y * height)`. Hands with a landmark count other than 21 are skipped. Missing handedness → `"Unknown"`.
- If the model file does not exist, raise `FileNotFoundError` with the path in the message (English; user-facing Russian messages are handled by the app later).

## Constraints
- No camera, display or network in the module or tests. Do not download anything.
- Do not modify `models/`.

## Ownership
`tmpmask/tracker.py`, `tests/test_tracker.py`.
