# 02-06: Screenshots and video recording

## Target
New module `tmpmask/capture.py` and its tests.

## Change
```python
def timestamp_name(prefix: str, ext: str, now: datetime) -> str: ...  # "tmpmask_20261014_153012.png"

def save_screenshot(frame: np.ndarray, output_dir: Path, now: datetime | None = None) -> Path: ...

class Recorder:
    def __init__(self, output_dir: Path, fps: float = 30.0): ...
    @property
    def is_recording(self) -> bool: ...
    @property
    def path(self) -> Path | None: ...      # current or last file
    def start(self, frame_size: tuple[int, int], now: datetime | None = None) -> Path: ...  # (width, height)
    def write(self, frame: np.ndarray) -> None: ...  # no-op when not recording; resizes if size differs
    def stop(self) -> Path | None: ...
```
- Names: `tmpmask_YYYYmmdd_HHMMSS.<ext>` with prefix `tmpmask`; if the file already exists add `_1`, `_2`, … before the extension.
- `output_dir` is created (`parents=True, exist_ok=True`) on first save/start.
- Video: `cv2.VideoWriter` with fourcc `mp4v`, extension `.mp4`. `start` while recording raises `RuntimeError`; `stop` when not recording returns `None`. If the writer fails to open, raise `RuntimeError`.
- `save_screenshot` writes PNG via `cv2.imwrite`; raise `RuntimeError` if it returns False.

## Constraints
- No user-facing text (messages are produced by the app). No display, no camera.
- Tests write only into pytest's `tmp_path`.

## Ownership
`tmpmask/capture.py`, `tests/test_capture.py`.

## Observable acceptance
Tests: name format for a fixed datetime; collision suffix `_1`; screenshot readable back with `cv2.imread` and equal shape; recorder writes 10 frames → `.mp4` exists, size > 0 and `cv2.VideoCapture` reports ≥ 1 frame; double start raises; stop when idle returns `None`; frame of another size does not raise.
