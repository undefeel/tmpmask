# 05-02: Integrate the "sabertooth" overlay filter

## Target
Existing app: `tmpmask/filters.py` (`FILTER_IDS`, `get_filter`, `next_filter_id`), `tmpmask/app.py` (`run` main loop, step 7 calls `render_portal`; digit keys `1`–`8` select `FILTER_IDS[idx]`), `tmpmask/texts.toml`, `README.md`, tests. Module `tmpmask/overlay.py` (from 05-01) provides `ASSETS_DIR`, `load_rgba(path)`, `render_overlay(frame, quad, image_rgba, opacity, outline=True)`; the asset is `tmpmask/assets/sabertooth.png`. Read them first.

## Change
1. `filters.py`: append `"sabertooth"` as the 9th and last id of `FILTER_IDS`. Add `OVERLAY_IMAGES: dict[str, str] = {"sabertooth": "sabertooth.png"}` (file names inside `overlay.ASSETS_DIR`) and `OVERLAY_OPACITY = 0.6`. `get_filter("sabertooth")` returns an identity function (returns a copy) with a docstring saying overlay filters are rendered by `tmpmask.overlay`; all other filters unchanged.
2. `app.py` `run`: load each overlay image lazily once (cache per id, via `overlay.load_rgba(overlay.ASSETS_DIR / name)`). Step 7: if `current` is in `OVERLAY_IMAGES` → `clean = render_overlay(frame, smoothed, image, opacity * OVERLAY_OPACITY)`; otherwise the existing `render_portal` call. Digit keys: `1`…`9` select `FILTER_IDS[int(ch) - 1]` (generalize to `len(FILTER_IDS)`, max 9). Nothing else in the loop changes.
3. `tmpmask/texts.toml`: add `sabertooth = "Саблезуб"` at the end of `[filters]`; in `messages.startup_hint` change `1–8` to `1–9` (keep the column alignment). No other text changes.
4. `README.md`: in the controls table change `` `1`–`8` `` to `` `1`–`9` ``; in the "Номера фильтров" line append `, 9 — Саблезуб` (before the final period, i.e. `… 8 — Контуры, 9 — Саблезуб.`); in the CLI options table append `` `sabertooth` `` to the `--filter` values list; in the intro sentence listing filter examples nothing changes. No other README changes.
5. Tests:
   - `tests/test_filters.py`: the "every filter changes the frame" property excludes ids in `OVERLAY_IMAGES`; add a test that `get_filter("sabertooth")` returns an equal copy (not the same object) and that `FILTER_IDS[-1] == "sabertooth"` and `len(FILTER_IDS) == 9`.
   - `tests/test_texts.py`: keep passing (filters table must equal `FILTER_IDS`).
   - `tests/test_app.py`: key `9` switches to sabertooth (message with `filter_name("sabertooth")`); with two fake hands forming a large portal and filter `sabertooth`, after enough frames for full fade-in the output centre of the portal differs from the input and matches neither the pure input nor any classic filter output; a pixel outside the portal is unchanged.

## Constraints
- Do not modify `tmpmask/overlay.py`, `tmpmask/portal.py`, `tmpmask/assets/`, `tools/`, `docs/`.
- No Russian literals in `tmpmask/*.py`; Russian only in `texts.toml`/README exactly as given above.

## Ownership
`tmpmask/filters.py`, `tmpmask/app.py`, `tmpmask/texts.toml`, `README.md`, `tests/test_filters.py`, `tests/test_app.py`, `tests/test_texts.py`.
